Типографіка та Текст

Це приклад основного тексту. Nectar.css використовує системні шрифти для максимальної чіткості. Посилання виглядають ось так (зверніть увагу на підкреслення), а при наведенні вони змінюють колір. Жирний текст виділяється кольором, а курсив додає акцент.

Можна використовувати виділення тексту, код всередині рядка, клавіатурні скорочення Ctrl+C та формули: E = mc2.

Цитати мають вертикальну лінію зліва і курсивний стиль. Вони виглядають як думки вголос або примітки на полях.

// Приклад блоку коду (функція JS)
function hello() {
    console.log("Nectar is sweet!");
    return true;
}
